Privacy Policy — PostingAgent

Last updated: 11 August 2026

PostingAgent is a private, single-user tool. It uploads videos that the operator has produced to the operator's own TikTok account. It is not offered to the public and has no other users.

What data the app handles

  • TikTok access and refresh tokens. Issued by TikTok when the operator authorises the app. Used only to call TikTok's Content Posting API.
  • Basic profile information (open ID, display name, avatar URL), retrieved through the user.info.basic scope so the app can confirm which account it is posting to.
  • Video files and their captions, created by the operator and sent to TikTok.

Where the data is stored

Tokens are stored in a local environment file on the operator's own computer. No data is transmitted to any server other than TikTok's own API endpoints. There is no database, no analytics service, and no third-party processor.

What the app does not do

  • It does not collect data about any TikTok user other than the operator.
  • It does not read comments, messages, follower lists, or other users' content.
  • It does not sell, share, or disclose any data to anyone.
  • It does not use data for advertising or profiling.

Retention and deletion

Tokens are kept only while the app is in use. The operator can revoke the app's access at any time in TikTok under Settings, Security and permissions, Manage app permissions. Revoking access invalidates the stored tokens immediately. Deleting the local environment file removes them from the computer.

Children

The app is not directed at children and is used only by its operator.
